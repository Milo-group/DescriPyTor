MolFeatures

MolFeatures is a Python toolkit for molecular descriptor workflows. It helps you turn quantum-chemistry outputs into tabular descriptors, assemble feature matrices, and search regression or classification models for structure-property analysis.

Workflow Layers

M1_pre_calculations
Input preparation and submission helpers for external calculations.
M2_data_extractor
Descriptor extraction from feather files, Gaussian logs, cube files, and XYZ geometries.
M3_modeler
Regression and classification model search, validation, plotting, and reporting.

Why use it

  • Convert Gaussian- or geometry-derived outputs into reusable descriptor tables.
  • Inspect molecules and choose atom-based descriptors interactively.
  • Build feature matrices for downstream QSAR or mechanistic modeling.
  • Compare regression and classification models across many descriptor combinations.
  • Keep modeling results cached in SQLite so large searches can be resumed.

Installation

python -m pip install -U pip
python -m pip install -e .

For notebooks:

python -m pip install -e ".[notebooks]"

For development tools:

python -m pip install -e ".[dev]"

Some workflows also require external chemistry software that is not installed through pip, such as Gaussian and Open Babel.

Quick Start

Explore the CLI

python __main__.py --help

Run the GUI

python __main__.py gui

Extract features from a saved input

python __main__.py extractor \
  --input Getting_started_with_examples/feather_example/input_example.json \
  --output feature_set \
  --feather_directory Getting_started_with_examples/feather_example

Run model search

python __main__.py model \
  --mode regression \
  --features_csv path/to/features.csv \
  --target_csv path/to/targets.csv \
  --y_value output \
  --min-features 1 \
  --max-features 4 \
  --top-n 20 \
  --threshold 0.70 \
  --n_jobs 16

Modeling workflow pattern from the notebooks

import os
import sys

ROOT_DIR = r"C:\Users\edens\Desktop\DescriPytor\DescriPyTor-main\MolFeatures"
sys.path.append(ROOT_DIR)
sys.path.append(os.path.join(ROOT_DIR, "M3_modeler"))
os.chdir(ROOT_DIR)

from modeling import LinearRegressionModel

csv_path = os.path.join(
    ROOT_DIR,
    "Getting_started_with_examples",
    "modeling_example",
    "Linear_Dataset_Example.csv",
)

csv_filepaths = {
    "features_csv_filepath": csv_path,
    "target_csv_filepath": "",
}

regression_model = LinearRegressionModel(
    csv_filepaths,
    process_method="one csv",
    y_value="output",
    leave_out=[],
    min_features_num=2,
    max_features_num=3,
)

results = regression_model.search_models(top_n=20, threshold=0.70, n_jobs=16)
