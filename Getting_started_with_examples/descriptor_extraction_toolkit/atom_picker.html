▶ How to use
Extract CSV runs feature extraction and shows the table here. Use Download CSV to save it.
Model tab: pick an existing column or paste outputs, then run linear regression.
Save picks writes run_config.json if you want to rerun later:
python descriptor_extractor.py --config run_config.json
Python tab = paste into a notebook as answers_dict.
