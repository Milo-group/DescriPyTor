5 · Validation Checklist

    

      same molecule namessame atom order1-based indices
      
Feather, XYZ, and log-derived tables merge by molecule name. Atom selections must refer to the same ordering as the displayed structure.

    

    

      freq jobNBO/pop datadipole
      
Vibrations, charges, and dipole features only appear when the Gaussian log actually contains those blocks.
