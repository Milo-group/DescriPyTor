DescriPyTor

Install + GUI · one page

Use Docker. Chemistry software is already in the image. Four steps, then two links in the browser.

Install

1

Docker Desktop

Install from docker.com. Wait until it says the engine is running.

2

Get the code

Clone the repo and make a work folder for your files.

3

Start it

From the repo folder: docker compose up --build. First time takes several minutes. Leave the terminal open.

4

Open the GUIs

Two local pages. Put molecules in work/ on your computer; the GUI sees them as /work/.

git clone https://github.com/Milo-group/DescriPyTor.git cd DescriPyTor mkdir work docker compose up --build

Open these pages

http://localhost:7432/visual
3D atom picker Start here. Caffeine loads as a demo. Click atoms on the left; set the workflow on the right. Atom numbers are 1-based (Gaussian style).
http://localhost:7432/
Feature extraction GUI Same engine, form-based, if you already know the atom indices. Streamlit is at localhost:8503.

http://localhost:7432/visual — 3D picker. Load your own file with Choose File.

http://localhost:7432/ — feature GUI.

Your files

On your computer DescriPyTor\work\molecule.feather
→
In the GUI, type /work/molecule.feather

Drop .feather, .xyz, or CSV into work/. Results written to /work appear in that same folder. Stop with Ctrl+C, or docker compose down.

In the picker

1 Load .feather or .xyz → 2 Click atoms (1-based) → 3 Extract → 4 Optional: model

Example molecules (26 substituted benzenes) ship with the package. Gaussian .log files: convert first with descripytor logs_to_feather.

If something fails

What you seeWhat to do
Cannot connect to DockerStart Docker Desktop and wait until it is idle
Port 7432 or 8503 already in useClose the other app using that port
RDKit / Morfeus errors on pipUse Docker instead

Without Docker (conda already set up)

conda create -n descripytor python=3.10 conda activate descripytor pip install "descripytor[gui,webapp]" descripytor gui

That last command opens the desktop window. For the same browser picker as Docker, clone the repo and run python M2_data_extractor/gui_server.py, then open localhost:7432/visual.
