DescriPyTor

Install + GUI · one page

Start with conda and pip. Open one local URL. Use Docker only if that fails, or you need xTB and extra engines.

Install

1

Clone + conda

Clone the repo. Create a Python 3.10 env and activate it.

2

Install

From the repo folder: pip install -e .

3

Start the GUI

descripytor visual — leave that terminal open.

4

Open the picker

In a browser: http://localhost:7432

git clone https://github.com/Milo-group/DescriPyTor.git cd DescriPyTor conda create -n descripytor python=3.10 conda activate descripytor pip install -e . descripytor visual

If RDKit fails: conda install -c conda-forge rdkit

The 3D picker is http://localhost:7432. The form-only GUI is http://localhost:7432/forms.

Open these pages

http://localhost:7432
3D atom picker Start here. Caffeine loads as a demo. Click atoms on the left (1-based). Load .xyz or .feather, then Save picks.
http://localhost:7432/forms
Feature extraction GUI Same engine, form-based, if you already know the atom indices.

http://localhost:7432 — 3D picker. Load .xyz or .feather, click atoms, Extract CSV, then Model.

http://localhost:7432/forms — feature GUI.

In the picker

1 Load .feather or .xyz → 2 Click atoms (1-based) → 3 Extract CSV → 4 Model tab: output + OLS → 5 Optional: Advanced

Example molecules (10 substituted benzenes) ship with the package. Gaussian .log files: convert first with descripytor logs_to_feather.

If something fails

What you seeWhat to do
RDKit / Morfeus import errorsconda install -c conda-forge rdkit, then Docker below
Port 7432 already in useClose the other app using that port

Docker (last resort / full toolkit)

Use this if conda still fails, or you need Streamlit, xTB, and extra engines. Install Docker Desktop, wait until the engine is running, then from the clone:

mkdir work docker compose up --build

First build takes several minutes. Then Streamlit is at http://localhost:8503. Drop files in work/; in the GUI type /work/yourfile.feather. Stop with Ctrl+C, or docker compose down.

On your computer DescriPyTor\work\molecule.feather
→
In the Docker GUI, type /work/molecule.feather
