record in [STERIMOL_FIXES.md](STERIMOL_FIXES.md). Tag `paper-v3` is unaffected: the paper's
numbers are rebuilt from that tag, and everything below is on `main` after it.

## Found, not changed: these alter existing numbers and need a decision

| issue | detail | option |
|---|---|---|
| **Stretch score does not measure a stretch** | Each mode is scored `|dᵃ·b| + |dᵇ·b|`. That rewards both atoms moving *together* along the bond as much as moving apart, which is why the README warns "a C–H stretch can beat your carbonyl". `b` is the raw bond vector, while the README says û, so `Amplitude` also scales with bond length (the chosen mode is unaffected). | score `|(dᵇ − dᵃ)·û|`, the relative displacement along the unit bond vector |
| **Metal neighbours count toward CPK type** | In `nob_atype`, `metal_complex.nob_types` and the JS `atomTypes`, a pyridine N bound to Cu counts 3 neighbours and is typed as an amine (1.50 Å) instead of N6 (1.70 Å); a metal-bound carbon moves up one type | count only non-metal neighbours. This changes Sterimol near every donor atom, including CS3's |
| **Dihedrals are unsigned (0–180°)** | `calc_angle_between_atoms` uses arccos of the two normals, so enantiomeric or ±60° rotamers are identical | signed dihedral (atan2), or report both |
| **Grouped dipole input is ambiguous** | `get_dipole_gaussian_df([[o…], [y…], [p…]])` is read as three separate frames when each group has ≥ 3 atoms | a separate argument for grouped y/plane selectors |
| **B1 resolution about ±0.01 Å** | B1 is a minimum that usually sits on a kink (two atoms tie), and the scan samples it every 1°, so where the scan starts moves B1 by up to 0.01 Å. The alcohol test table moved by 0.009 Å for exactly this reason | exact minimisation (rotating calipers on the projected discs) instead of a grid |
| dead code with 0-based labels | `calc_bonds_length`, `calculate_bond_lengths_matrix`, `calculate_angles_matrix` label or index 0-based while taking 1-based bond tables; nothing calls them | delete, or fix if kept |
